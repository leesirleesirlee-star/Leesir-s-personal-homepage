## 4. 交互设计

### 4.1 原则对齐

PRD 第 8 节将 Complex animations 排除在 V1 之外，V2.3 才加入 micro-interactions / subtle animations。
因此苹果官网式交互分两期落地：

### 4.2 V1 交互清单（克制、基础）

| 编号 | 交互 | 说明 | 解决的问题 |
|---|---|---|---|
| INT-01 | 锚点平滑滚动 | 点击导航丝滑滚动到对应板块 | 单页结构下避免生硬跳变 |
| INT-02 | 板块入场淡入上移 | 元素进入视口时一次性 fade-in + 16px 上移，无连续动画 | 让页面有"流动呈现"感，保持克制 |
| INT-03 | 导航栏毛玻璃 | 滚动后导航背景变为半透明 + backdrop blur | 固定导航与内容重叠时保持可读 |
| INT-04 | 主题切换过渡 | 浅/深色切换时颜色 0.3s 渐变 | 避免闪烁式生硬切换 |
| INT-05 | 语言即时切换 | JS 切换文案，不刷新页面 | 双语访客无缝阅读 |
| INT-06 | 卡片 hover 浮起 | 项目卡片 hover 时轻微上浮 + 阴影加深 | 提示可点击性 |

### 4.3 留待 V2 的交互（届时作为"有目的的迭代"证据）

- 滚动驱动的粘性叙事（sticky 分镜）
- 视差与连续缩放效果
- 更细腻的 micro-interactions

### 4.4 本人确认（2026-09-03 第二轮）

- 设计方案通过；**V1 即融入苹果风格的简洁设计**：大留白、全屏分节、细腻排版层级、流畅滚动、克制动效；复杂滚动叙事仍留 V2
- 志愿者论坛小程序状态标记为**进行中**
- **Git 工作流约定**：每完成一个版本即 git commit + 打 tag（如 v1.0）作为可回退 checkpoint

## 5. 视觉设计方向（学院风 · 双主题）

### 5.1 浅色主题

- 背景：象牙白 `#FAF9F6`
- 正文文字：深墨蓝 `#1A2332`
- 次要文字：`#5A6472`
- 点缀色（学院蓝）：`#2C4A8A`
- 卡片/分隔：`#ECEAE3`

### 5.2 深色主题

- 背景：墨蓝黑 `#0F141B`
- 正文文字：米白 `#EDEAE2`
- 次要文字：`#9AA3AE`
- 点缀色：浅学院蓝 `#7A9BD1`
- 卡片/分隔：`#1B2330`

### 5.3 字体策略

- 标题：衬线体（学院感）— 英文 Georgia/"Times"系，中文思源宋体/系统宋体
- 正文：无衬线 — 英文系统字体栈，中文思源黑体/系统黑体
- V1 使用系统字体栈保证本地零依赖；Web Font 留待 V2 评估

## 6. 技术方案（对齐 PRD 第 13 节）

- 纯 HTML / CSS / JavaScript，无框架、无构建工具
- Git 版本管理，V1 完成后打 checkpoint
- 双语实现：`data-i18n` 属性 + 内置词典对象 + localStorage 记忆
- 主题实现：CSS 自定义属性 + `data-theme` 切换 + localStorage 记忆
- 本地预览：直接打开 index.html 或简单静态服务器
